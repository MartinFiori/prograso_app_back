# Inicio del orquestador

Pegá este pedido en el Agent principal de Cursor, reemplazando el requerimiento:

> Actuá como orquestador principal siguiendo sdd/ORCHESTRATOR.md. Mi requerimiento es: [DESCRIBÍ LA FUNCIÓN]. Leé el código y los schemas, usá los subagentes SDD disponibles y prepará spec, plan, tareas y criterios de aceptación. Presentame el flujo propuesto y preguntame si cumple la función que necesito. Esperá mi aprobación antes de modificar código o tests. Después de aprobar, implementá, probá, verificá definiciones y documentá el contexto hasta completar los criterios o identificar un bloqueo real.

Para retomar:

> Retomá la feature [ID] siguiendo sdd/ORCHESTRATOR.md. Leé sus artefactos, respetá la aprobación vigente, verificá si la evidencia corresponde al código actual y continuá desde la primera tarea pendiente.

Para un ajuste:

> Quiero ajustar la feature [ID]: [CAMBIO]. Analizá el impacto sobre la spec y el plan; si cambia el alcance aprobado, presentame la revisión antes de implementarla.
